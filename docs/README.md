## Monorepo Layout

- `docs/`: Technical specifications, documentation, and deployment guides.
- `frontend/`: Next.js web application (App Router, Tailwind CSS, Lucide Icons, Docker).
- `backend/`: Convex functions, database schema, and authentication handlers.
- `ios/`: Native iOS app (Swift, SwiftUI, XcodeGen).
- `android/`: Native Android app (Kotlin, Jetpack Compose).
