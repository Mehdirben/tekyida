# AGENTS.md — Tekyida

IOU tracker PWA: Next.js 16 (App Router) + Convex backend + React 19 + Tailwind CSS v4.

## Commands

```bash
npx convex dev         # Must run FIRST — generates convex/_generated/ and .env.local
npm run dev            # Next.js dev server (separate terminal)
npm run build          # Production build (needs valid .env.local)
npm run lint           # ESLint with next/core-web-vitals + next/typescript configs
```

No test framework is configured. No typecheck script exists (run `npx tsc --noEmit` manually if needed).

## Architecture

- **Frontend**: `app/` is Next.js App Router. Root layout at `app/layout.tsx`, providers at `app/providers.tsx`.
- **Backend**: `convex/` is the Convex backend — queries, mutations, actions, schema. Has its own `tsconfig.json`.
- **`convex/_generated/`**: Auto-generated by `npx convex dev`. Never edit. Excluded from the convex tsconfig.
- **Path alias**: `@/*` → project root (configured in root `tsconfig.json`).
- **Convex imports**: Backend files import from `"./_generated/server"`, frontend uses `convex/react` and `@convex-dev/auth/react`.

## Provider Nesting Order

`ConvexClientProvider > ThemeProvider > LanguageProvider > SyncProvider` (in `app/providers.tsx`). Order matters.

## Convex Backend Patterns

- Auth: `@convex-dev/auth` with Password provider (`convex/auth.ts`).
- Auth check in every handler: `const userId = await getAuthUserId(ctx);` from `@convex-dev/auth/server`.
- User-scoped data: all tables have `userId` field; queries filter by authenticated user.
- `internalQuery`/`internalMutation` used for server-to-server calls (see `convex/users.ts`).
- Cascade deletes are manual (see `notebooks.ts` `remove` mutation).

## Database Tables

`notebooks` → `contacts` (by notebook) → `transactions` (by notebook, optional contact/experience). `experiences` groups transactions. All indexed by notebook/contact/experience.

## Offline Layer (custom, not a library)

- `lib/offlineQueue.ts` — IndexedDB mutation queue
- `lib/queryCache.ts` — IndexedDB query cache with reactive subscriptions
- `lib/optimisticUpdates.ts` — Applies mutations to cache for instant UI
- `hooks/useCachedQuery.ts` — Drop-in replacement for Convex `useQuery`
- `contexts/SyncContext.tsx` — Orchestrates queue flush and sync status

## Styling

Tailwind CSS **v4** via `@tailwindcss/postcss` plugin (not `tailwindcss` directly). Design tokens and glass effects live in `app/globals.css`. Theme toggle uses `localStorage` key `tekyida-theme` with inline script in `layout.tsx` to prevent flash.

## i18n

Custom implementation: `i18n/en.ts`, `i18n/fr.ts`, `i18n/LanguageContext.tsx`. No library. Language persisted in `localStorage`.

## Environment Setup

`.env.local` is auto-created by `npx convex dev`. Required vars: `CONVEX_DEPLOYMENT`, `NEXT_PUBLIC_CONVEX_URL`, `NEXT_PUBLIC_CONVEX_SITE_URL`. See `.env.example` for reference.

## Misc

- Mobile-first PWA: service worker at `public/sw.js`, manifest at `public/manifest.json`.
- `scripts/generate-icons.mjs` generates PWA icons.
- `web-haptics` library used for haptic feedback.
- HTML default lang is `fr`.
